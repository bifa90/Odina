# نشر الموقع — `odinaav.web.app`

> **الفكرة في سطر:** الموقع **واجهة عرض** فقط، ومصدر الحقيقة دائمًا **GitHub**.
> **الملف التنفيذي:** `tools/deploy-site.py` · **المانيفست:** `site/site.json`

---

معاينة D47 تحاكي النتائج ولا تشحن قاعدة قابلة للتنفيذ. حزمة بيانات الإصلاح المستقلة ضمن `build.yml` وإصدارات البرنامج، لا ضمن مانيفست الموقع.

## 1. لماذا أُعيدت كتابة السكربت

النسخة القديمة كانت **1136 سطرًا**، معظمها إصلاح لأعراض سببها واحد:

> **كانت تنشر المستودع كله، ثم تحاول إخفاء ما لا ينبغي نشره.**

ولذلك وُجد فيها:

| العَرَض | السبب | العلاج في النسخة الجديدة |
|---------|-------|---------------------------|
| `content hash doesn't match` | ملف السجل كان يُكتب **داخل المشروع** أثناء الرفع، فيتغيّر محتواه | السجل صار في `~/.cache/odina-logs/` — **خارج الموقع تمامًا** |
| 788 ملفًا تُرفع | `.git/**` لم تُستثنَ | لم يبقَ استثناء: **لا يُنشر إلا ما في المانيفست** |
| توقف عند 40% | 23 MB من `fonts/vendor/` تُرفع | الخطوط **لا تُنشر** أصلًا (CDN أو خط النظام) |
| `resolving hosting target` | ملف إعداد Firebase غير مكتمل | يُكتب مرة واحدة كاملًا داخل المستودع |
| 12 محاولة إعادة | كل شيء كان يُعاد من الصفر | لا حاجة لإعادة رفع المستودع |

**والفرق الجوهري:** القديمة كانت تُعدّل `firebase.json` **سرًا ثم تستعيده**. الجديدة تكتبه **مرة واحدة** ويبقى في المستودع — فلا يوجد شيء يُستعاد.

## 2. البنية

```
site/
├── site.json        ← المانيفست: ما يُنشر بالضبط
└── _build/          ← مخرج البناء (مُستثنى من git)
    ├── index.html           (من ui-preview.html)
    ├── locales.js           (القاموس المُولّد من ملفات Fluent)
    ├── proactive-preview.js (محاكاة محلية لسياسة الاحتواء)
    ├── signing.html
    ├── logo-review.html
    └── assets/logo/…
```

### `site/site.json`

```json
{
  "include": [
    "ui-preview.html",
    "signing.html",
    "locales.js",
    "proactive-preview.js",
    "logo-review.html",
    "assets/logo/svg/*.svg",
    "assets/logo/png/*/*.png",
    "README.md", "LICENSE", "NOTICE"
  ],
  "rename": { "ui-preview.html": "index.html" },
  "fonts_cdn_base": ""
}
```

**القاعدة:** **لا يوجد استثناء.** ما في `include` يُنشر، وما ليس فيه لا يُرى. الاستثناءات كانت مصدر كل الأعطال لأنها **قائمة لا نهائية** — والمانيفست **قائمة منتهية**.

### `fonts_cdn_base`

اتركه فارغًا لاستخدام خطوط النظام. يحذف البناء تعريفات `@font-face` المحلية من النسخة المنشورة فقط حتى لا يطلب المتصفح ملفات غير مرفقة؛ معاينة المصدر تظل تستخدم الخطوط المجاورة.
وحين ترفع الخطوط إلى موقعك، ضع الرابط هنا، و**السكربت يعيد كتابة كل `fonts/vendor/`** في HTML تلقائيًا:

```json
"fonts_cdn_base": "https://odinaav.web.app/fonts/"
```

## 3. الاستخدام

```bash
# معاينة ما سيُنشر — بلا رفع
python3 tools/deploy-site.py --dry-run

# معاينة محلية في المتصفح
python3 tools/deploy-site.py --serve

# النشر
python3 tools/deploy-site.py

# النشر مع تحديد المشروع
python3 tools/deploy-site.py --project odinaav
```

**البناء والمعاينة:** Python 3.10+ فقط. يطبع `--serve` عنوانًا محليًا (المنفذ 5000 افتراضيًا) ويخدم مجلد النشر وحده. لا يحتاج تسجيل دخول ولا يكتب إعدادات Firebase.

**للنشر العام فقط:**

```bash
npm i -g firebase-tools
firebase login     # مرة واحدة
```

## 4. الفحص قبل النشر — خمسة بنود

السكربت **يرفض النشر** إن فشل أي بند:

| # | الفحص | لماذا |
|---|-------|-------|
| 1 | `index.html` موجود | موقع بلا صفحة رئيسية = صفحة بيضاء |
| 2 | لا ملف > 2 MB | الملف الضخم هو ما يُسقط الرفع |
| 3 | الحجم الكلي ≤ 8 MB | حدّ يمنع تسلّل حزم لا تنتمي إلى الموقع |
| 4 | **لا `fonts/` · `docs/` · `tools/` · `locales/` · `.git/`** | هذه لا تنتمي لموقع عام |
| 5 | **كل مرجع محلي يُحلّ** | صورة مكسورة في صفحة العرض = انطباع سيئ |

**البند 5 هو المهم:** لو حذفت صورة شعار أو أعدت تسميتها، السكربت يرفض النشر **قبل** أن يرى المستخدم رمزًا مكسورًا.

## 5. ما أُزيل من النسخة القديمة — ولماذا بالضبط

| أُزيل | السبب |
|-------|-------|
| **التحديث الذاتي من git** (`git reset --hard`) | نشر موقع **ليس** سببًا لحذف تعديلاتك المحلية. ومن يُشغّل السكربت لا يتوقع أن يُستبدل مستوده |
| `safe_clean()` | تبعية لسابقتها: لا تحديث = لا تنظيف |
| 12 محاولة مع تأخير متزايد | محاولة واحدة + سبب واضح أفضل |
| تخفيض التزامن التلقائي | لزم فقط لأن الحجم كان هائلًا |
| `--debug` في المحاولات الأخيرة | نتيجة التخبّط لا علاح له |
| استثناءات مشروع آخر: `blogger/` · `worker/` · `content/courses/*/mp3/` · `AR2406` | **مجلدات لا وجود لها في Odina** — كانت تبقى من مشروع سابق |
| ثreshold الصور 100KB | خطأ في التصميم: من يُقرر ما يُنشر هو **المانيفست**، لا حجم الملف |
| ملف السجل داخل المشروع | السبب المباشر لـ`hash mismatch` |
| `PROJECT = ` (مقطوع) | **خطأ نحوي** كان يمنع تشغيل الملف أصلًا |

## 6. ما بقي من القديم — لأنه جيد فعلًا

| بقي | لماذا |
|------|-------|
| ألوان الطرفية ورسائل ✔ · ! · ✖ | واضحة ومتّسقة |

## 7. الترخيص

`tools/` كلها **MIT** (§`LICENSE-TOOLS`) — ومنها هذا السكربت.

`site/_build/` **مخرج بناء**، مُستثنى من git. لا يُرفع إلى المستودع، ولا يُعدّل يدويًا — فهو يُعاد إنشاؤه في كل تشغيل.
