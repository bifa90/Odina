# Odina — نصوص الشاشات والتنبيهات v1

> **الغرض:** هذه هي **R4** — قائمة كل جملة تظهر للمستخدم، بلغتها العربية، قبل أن تُترجم وقبل أن تُكتب في الكود.
> **المرجع:** `docs/odina-agent-prompt-v17.md` §2.1 (أسس الثقة) · §8 · §8.2.2
> **الملف المقابل:** `locales/ar/odina.ftl` — كل سطر هنا يجب أن يقابله مفتاح هناك.

---

## 1. القواعد التي حُكمت بها كل جملة

| # | القاعدة | كيف تُطبَّق |
|---|---------|-------------|
| 1 | **جملة واحدة** | كل تنبيه = سطر واحد + اسم الملف + المسار. لا فاصلتين متتاليتين |
| 2 | **ما حدث، لا ما هو التقنية** | «عُزل» لا «تم اكتشاف كائن خبيث» |
| 3 | **لا لوم** | لا «أنت سمحت»، لا «لم تُحدّث» |
| 4 | **لا وعد لا نُنجزه** | لا «حماية كاملة»، لا «100%» |
| 5 | **لا حذف في أي تنبيه** | الحذف في العزل فقط (§8.2.2) |
| 6 | **الشرح عند الطلب** | المصطلح الغامض يُسطَّر، ولا يُشرح في نفس السطر |
| 7 | **العاقبة مكتوبة على الزر** | «المنع — لن يعمل بعد الآن» لا زر «منع» فقط |

## 2. الشاشة الرئيسية

| العنصر | النص |
|--------|------|
| العنوان | **أنت محمي** |
| السطر الثاني | 3 جدران فعّالة · قاعدة التهديدات محدّثة |
| الجدران | قاعدة بيانات الملفات · الفحص السلوكي العميق · الحماية الاستباقية |
| حالة الجدار | فعّال · خامل · متوقف مؤقتًا |
| زر أساسي | **افحص الآن** |
| زر ثانوي | إيقاف مؤقت |
| عند الفحص | جارٍ الفحص… · **توقف** |
| بعد الفحص النظيف | **لم نجد شيئًا.** لا تُضف شيئًا — الصمت هو التأكيد (§2.1) |
| عند وجود نتيجة | انظر §3 |

**قرار:** لا تُعرض «آخر فحص منذ 3 ساعات» في الشاشة الرئيسية. المعلومة موجودة عند الطلب، وليست سببًا لقلق دائم.

## 3. التنبيهات الأربعة — النصوص الكاملة

### 3.1 مؤكد

```
⛔ [مؤكد]  أوقفنا تهديدًا معروفًا

PhotoTool.exe تهديد مؤكد وتم عزله — لم يُحذف.

المسار  C:\Users\Ahmed\Downloads\PhotoTool.exe        ⧉

[ فتح صندوق العزل ]     ▸ لماذا؟
```

| البند | النص | ملاحظة |
|-------|------|--------|
| العنوان | أوقفنا تهديدًا معروفي | — |
| الجملة | **… وتم عزله — لم يُحذف.** | الجملة الأهم في التطبيق كله |
| الزر | فتح صندوق العزل | **زر واحد فقط** — لا حذف، لا استرجاع |
| لا يختفي | — | التنبيه المؤكد لا يختفي من نفسه |

**لماذا «لم يُحذف» في الجملة نفسها؟** لأن المستخدم إن لم يقرأها سيفترض أن المكافح حذف الملف. والافتراض الخاطئ هنا هو الفرق بين ثقة وخوف.

### 3.2 مشتبه بشدة

```
⚠️ [مشتبه بشدة]  برنامج يحاول الوصول إلى ملفاتك

PhotoTool.exe يعدّل ملفات في المستندات — أوقفناه مؤقتًا.

[ السماح ]   [ المنع ]      مؤقتًا ⓘ     ▸ لماذا؟
```

| الزر | العاقبة المكتوبة (تظهر عند التمرير) |
|------|--------------------------------------|
| السماح | سيعمل هذا البرنامج، وسنراقبه فقط |
| المنع | **لن يعمل هذا البرنامج بعد الآن** |

**المدة:** 60 ثانية. **عند الانتهاء:** المنع.

### 3.3 خطر متوسط (كراك)

```
🎣 [خطر متوسط]  يبدو أنها أداة كسر حماية

setup-key.exe يتجاوز حماية ترخيص برنامج مدفوع.

[ انقله جانبًا ]   [ اسمح به ]     ▸ لماذا؟
```

**قرار مقصود:** لا نقول «خبيث». أداة الكسر ليست فيروسًا بالضرورة، والمستخدم يعرف ما فعله. نقول ما نراه ونترك القرار — **ولا نُشعره بالاتهام**.

**عند الانتهاء:** لا عزل تلقائي. هذا المستوى لا يُتخذ فيه قرار عن المستخدم.

### 3.4 مشتبه

```
ℹ️ [مشتبه]  هذا البرنامج غير مألوف

newapp.exe جديد هنا ويتصرف بغرابة.

[ السماح ]   [ المنع ]     ▸ لماذا؟
```

**المدة:** 30 ثانية. **عند الانتهاء:** المنع مؤقتًا + فحص عميق.

### 3.5 ما لا يظهر أبدًا

| لا | لماذا |
|----|-------|
| ❌ «تم اكتشاف 3 تهديدات» | رقم بلا قرار = قلق بلا فائدة |
| ❌ «جهازك في خطر» | لا نقول ما لا نعرف |
| ❌ نسبة الثقة «87%» | توهم دقة غير موجودة (§8 من `scoring-spec`) |
| ❌ «قم بالترقية للحماية الكاملة» | لا اشتراك في Odina |
| ❌ أي تنبيه لما دون 50% | عتبة الازعاج |

## 4. «لماذا؟» — صفحة الشرح عند الطلب

عند الضغط على «لماذا؟» يُفتح **سطران لا فقرة**:

```
سجّل هذا الملف في مجلد التنزيلات، وحاول إضافة نفسه إلى بدء التشغيل.
هذان السببان رفعا الحذر، لا اسم الملف.

[ ما معنى «بدء التشغيل»؟ ]  ← كلمة مسطّرة تفتح بحثًا بلغتك
```

**القاعدة:** نصف المعلومات في التنبيه، ونصفها في «لماذا؟». ومن يريد المزيد، يضغط على الكلمة المسطّرة — **ولا نُغرق الجميع لخدمة واحد**.

## 5. تنبيه USB

### أثناء الفحص

```
USB_32GB
▓▓▓▓▓▓░░░░░░░░  34%
فحص سريع · 11 ملفًا · 0 تنبيه
```

### النظيف

**يختفي الشريط بعد 3 ثوانٍ — بلا رسالة.** لا «تم الفحص بنجاح»، لا «كل شيء آمن». **الصمت هو التأكيد** (§2.1 الأساس الثالث).

### المصاب

```
⚠️ USB_32GB فيه ملف مصاب

autorun.inf يفتح برنامجًا تلقائيًا عند الإدخال.

[ انقله جانبًا ]   [ اسمح به ]
```

**لغة الجملة:** «USB فيه ملف مصاب» — لا «تم اكتشاف تهديد في الجهاز». نتكلم عن الشيء كما يراه المستخدم في يده.

## 6. صندوق العزل — المكان الوحيد فيه «حذف»

```
صندوق العزل
كل شيء يبقى حتى تقرر أنت · لا حذف تلقائي أبدًا

PhotoTool.exe
C:\Users\Ahmed\Downloads\PhotoTool.exe
تهديد مؤكد · يُحفظ 30 يومًا
[ احتفظ به ]  [ استرجاع ]  [ حذف نهائي ]
```

| الزر | النص المعروض للعاقبة |
|------|----------------------|
| احتفظ به | يبقى هنا بلا حدّ زمني |
| استرجاع | **يعود إلى مكانه الأصلي** — وسيُفحص مرة أخرى |
| حذف نهائي | **لا يمكن التراجع.** لا نسخة أخرى |

**تنبيه الـ30 يومًا:**

```
منذ 30 يومًا وهذه الملفات في العزل:
4 ملفات · 12 MB
[ احتفظ بها ]  [ راجعها ]  [ حذف ما اخترته ]
```

**و«حذف ما اخترته» لا «حذف الكل».** لا نُسهّل حذف ما لم يختره المستخدم بعينه.

## 7. الإيقاف — مستويان، وشاشتان

### 7.1 إسكات التنبيهات (Pause)

```
إسكات التنبيهات
مدة: 10 دقائق · 30 دقيقة · ساعة · حتى إعادة التشغيل

ما زلنا نحميك. أوقفنا التنبيهات فقط.
أي ملف مصاب سيُعزل بصمت، وسنعرضه عليك عند العودة.

[ تأكيد ]
```

| البند | النص |
|-------|------|
| حلقة الرجوع | «ما زلنا نحميك» — **صادقة**، فالجدران لا تُطفأ |
| الوعد | «سنعرضه عليك عند العودة» — لا نُخفي ما حدث بصمت |
| الشريط | «التنبيهات متوقفة مؤقتًا · الحماية تعمل» |
| التذكير | مرة واحدة قبل 5 دقائق من العودة |

### 7.2 إيقاف الحماية — الشاشة الحمراء

```
⚠  خطر شديد

لن نتوقف عن التنبيه — سنتوقف عن الحماية.
لن يُفحص أي ملف، ولن يُمنع أي تهديد.
جهازك يصبح غير محمي تمامًا.

القرار قرارك، والمسؤولية عليك أثناء هذه المدة.

اختر المدة:
[ ٣٠ دقيقة ] [ ساعة ] [ حتى نهاية ساعة الذروة ] [ حتى إعادة التشغيل ]

تستطيع إعادة الحماية في أي لحظة — بلا كلمة مرور.

                          [ إلغاء ]  [ إيقاف الحماية ]
```

**لماذا هذه الجمل بالذات:**

| الجملة | الغاية |
|--------|--------|
| «لن نتوقف عن التنبيه — سنتوقف عن الحماية» | تنفي الفهم الخاطئ الشائع بأن الإيقاف = كتم إشعارات |
| «جهازك يصبح غير محمي تمامًا» | لا تلطيف. الكلمة الصريحة وحدها تُنتج قرارًا واعيًا |
| «القرار قرارك، والمسؤولية عليك» | المسؤولية في صلب الشاشة، لا في هامش |
| «بلا كلمة مرور» | تُعلن أننا لا نبتزّه — وهذا ما يجعل الإيقاف خيارًا لا هروبًا |

**وممنوع في هذه الشاشة:** صندوق «أوافق على الشروط» · نافذة تهويل ثانية · كلمة مرور · عدّاد تنازلي يمنعه.

### 7.3 أثناء الإيقاف (المستوى الثاني)

| الموضع | النص |
|--------|------|
| الشاشة الرئيسية | **الحماية موقوفة** · حتى 14:30 · بقرارك |
| الدرع | رمادي، بلا علامة صح |
| الزر | **أعد الحماية** — بضغطة واحدة، بلا سؤال |
| صينية النظام | غير محمي — بقرارك |
| التذكير | **مرة واحدة** قبل 5 دقائق: «لديك 5 دقائق متبقية على إعادة الحماية تلقائيًا» |

**ولا تذكير بعد القرار.** من يوقف الحماية ثم يُعاتَب كل ساعة، يُطفئ الخدمة من مدير المهام بدل الواجهة — فيخسر كل شيء: لا حماية ولا شفافية.

### 7.4 ما لا يُسمح به — وبرسالة واحدة

| الحالة | الرسالة |
|--------|---------|
| ملف معزول لم يُحسم | يوجد ملف معزول لم تحسمه بعد. راجعه أولًا. |
| فحص جارٍ | هناك فحص جارٍ. انتظره أو أوقفه أولًا. |
| تهديد لم يُعالَج | يوجد تهديد لم يُعالَج بعد. لا نُوقف الحماية وتهديدها مفتوح. |

**لا نمنعه — نطلب منه إنهاء ما بدأه.** والفرق بين الاثنين هو فرق النبرة كلها.

## 8. الأخطاء — كيف نعتذر

| الحالة | النص |
|--------|------|
| إنذار كاذب | **أخطأنا في هذا الملف — أصلحناه.** لا نُبرّر، ولا نشرح داخليًا |
| تعذّر العزل | لم نستطع عزل الملف لأنه مفتوح الآن. [ إعادة المحاولة لاحقًا ] |
| تعذّر التحديث | قاعدة التهديدات لم تُحدَّث منذ 7 أيام. لا إشعار يومي |
| خدمة متوقفة | أعدنا تشغيل الحماية. لم يتأثر شيء |

**قاعدة الاعتذار:** في **نفس الشاشة**، لا في صفحة أخرى. ومن يُخطئ في نفس المكان يجب أن يعتذر فيه.

## 9. قائمة الترجمة — ما يجب أن يُترجم وما لا

| يُترجم | لا يُترجم |
|--------|-----------|
| كل نصوص الشاشات أعلاه | أسماء الملفات (`PhotoTool.exe`) |
| أسماء الأزرار | المسارات |
| رسائل الخطأ | أسماء الأوضاع التقنية في السجل |
| نصوص التلميحات | `Odina` |

**والقاعدة الحاكمة (§3.9.2):** الترجمة التي تُخفّف التحذير **خطأ أمني** لا لغوي. مثال: حذف «مؤقتًا» من جملة الإيقاف يجعل المستخدم يظن أن البرنامج أُوقف نهائيًا.

## 10. بوابة القبول (R4)

- [ ] كل تنبيه = جملة واحدة + ≤ زرّين
- [ ] لا زر حذف في أي تنبيه
- [ ] التنبيه المؤكد يعرض جملة «لم يُحذف»
- [ ] كل زر يحمل عاقبته
- [ ] لا نسبة مئوية في أي تنبيه
- [ ] انتهاء التنبيه = القرار الآمن
- [ ] كل نص هنا له مفتاح في `locales/ar/odina.ftl`
- [ ] شاشة إيقاف الحماية تحمل **ثلاث جمل**: ماذا يتوقف · المسؤولية · الإرجاع بلا كلمة مرور
- [ ] لا صندوق «أوافق على الشروط» في أي مسار
- [ ] الإيقاف يُعاد **بضغطة واحدة** بلا كلمة مرور
- [ ] لا مدة «دائمة» في أي خيار
- [ ] صفر نص مضمَّن في الكود (§18.2.9)

---

**الخطوة التالية:** مراجعة رامي لهذه النصوص **قبل** ترجمتها. النص العربي يُثبَّت أولًا، ثم تُترجم العشرة — لأن ترجمة نص سيتغيّر هي عمل مهدور.
