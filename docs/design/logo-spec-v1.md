### ما تغيّر بعد قرار رامي (v2)

| البند | v1 (مقترحي) | **v2 (المعتمد)** |
|-------|--------------|-------------------|
| سماكة القوس | 60px (خط رفيع) | **112px** (جسم ممتلئ) |
| كثافة اللوحة | 76% | **88%** |
| العمود | مستدير القمة 72px عرضًا | نفسه (لم يتغيّر) |
| التوزيع اللوني | نفسه | **كحلي جسم + أبيض فراغ + ذهبي عمود** (من نسختك القديمة) |
| الأيقونة عند 16px | خط 108 | **خط 150** (لأن الجسم أثقل) |

**ما أُخذ منه:** الفكرة كاملة (قوس + عمود + إحساس O) — وهي فكرتك، ونُفِّذت هندسيًا.

## 3. المواصفة الهندسية النهائية **v2 — معتمدة من رامي**

> **قرار رامي (2026-11-15):** الشكل الهندسي للملف الثاني (قوس واسع + عمود مستدير)
> مع **توزيع الألوان من النسخة القديمة**: كحلي ممتلئ + فراغ أبيض داخلي + عمود ذهبي.
> ثم ضُبطت **الكثافة** لتطابق إحساس المرجع: المحتوى يملأ ≈88% من اللوحة.

```
viewBox:        1024 × 1024
Content scale:  1.13 (المحتوى يملأ ≈88% — القوس من ≈215 إلى ≈810)
Safe margin:    ≈12% (بعد التحجيم: 118px)
Stroke:         112px (≈11% من العرض) — «جسم ممتلئ» لا خط رفيع
Apex:           عند y=176 — مدبّب لكن غير حاد (C-curve لا زاوية)
Shoulders:      مستقيمة قصيرة من y=500 إلى y=688 (تعطي «بوابة» لا «بيضة»)
Base:           قوس دائري يُغلق الشكل عند y≈852 → يقرأ O
Pillar:         من y=566 إلى y=756، عرض 72، أعلى مستدير (نصف قطر 26)
الألوان:        كحلي #0A2540 (القوس) + ذهبي #D4AF37 (العمود) — لونان فقط
```

### متغيّر الأحجام الصغيرة (≤ 32px)

```
يمنع العمود الذهبي (يختفي ويصبح ضجيجًا)
يزيد سماكة الخط إلى 108 (≈10.5%)
يبطّئ القمة (blunter) لتُقرأ عند 16px
يُختبر فعليًا — الصورة أدناه
```

## 4. الأصول المُنتَجة

| الملف | المحتوى |
|-------|---------|
| `svg/odina-icon-light.svg` | كحلي على شفاف (الأساسية) |
| `svg/odina-icon-dark.svg` | ذهبي على كحلي (الوضع الداكن) |
| `svg/odina-icon-mono-{black,white}.svg` | أحادي اللون |
| `svg/odina-icon-16-light.svg` | نسخة 16px المبسّطة |
| `png/{light,dark,mono-black,mono-white}/odina-{1024…16}.png` | 9 مقاسات × 4 نسخ = **36 ملفًا** |
| `odina.ico` | 7 إطارات: 16/24/32/48/64/128/256 (PNG-compressed) |
| `press/odina-2048-sand.png` | غلاف صحفي بخلفية رملية إجرائية `#E8D5A9` |

**الحجم الكلي:** ≈ 4MB (معظمه ملف 2048 والنسخ الكبيرة). أصول الإصدار النهائي ستُضغط إلى WebP/ICO فقط.

## 5. نتائج اختبار الأحجام

| المقاس | النتيجة | ملاحظة |
|--------|---------|--------|
| 1024 / 512 | ✅ | نظيف، الحواف حادة |
| 256 / 128 / 64 | ✅ | العمود واضح |
| 48 | ✅ | العمود ما زال مقروءًا |
| **32 / 24 / 16** | ✅ | **النسخة المبسّطة تعمل** — القوس مقروء، لا تلاصق |

**الاختبار القاسي:** عند 16px يبقى الشكل «بوابة/حرف O» ولا يتحول إلى بقعة — وهو شرط §36.3.
