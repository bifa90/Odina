# نافذة سطح المكتب (`src-tauri/`) — أول شاشة حقيقية

**القرار:** [D125](decisions.md) — النافذة **Tauri 2** كما في [D42](decisions.md)، تُبنى الآن
كنسخة نهائية لا كنموذج، على نظامين: **Ubuntu** للتطوير و**Windows 11** للسوق.

هذه الورقة تشرح ما بُني، وكيف يُبنى عندك، وما لا يفعله بعد — بلا وعد.

## 1. ما في الشجرة الآن

| الملف | الدور |
|---|---|
| `src-tauri/Cargo.toml` | حزمة `odina-shell`، **خارج مساحة العمل الجذرية** عمدًا (اقرأ §3) |
| `src-tauri/src/lib.rs` | أمر `home`: يقرأ الحالة من المقيم، ويترجمها من ملفات اللغات، ويُرجع ما يُرسم |
| `src-tauri/src/main.rs` | نقطة الدخول، بلا وحدة طرفية في إصدار Windows |
| `src-tauri/ui/index.html` | الهيكل فقط: **مفاتيح لا نصوص** |
| `src-tauri/ui/app.css` | نفس رموز `ui-preview.html` (الألوان والمسافات والظل) |
| `src-tauri/ui/app.js` | يسأل `home` كل ثانيتين، ويتبع النظام في المظهر (D123) |
| `src-tauri/tauri.conf.json` | نافذة واحدة، CSP مغلق على `self`، حزمة `deb` و`nsis`، أيقونات المشروع |
| `src-tauri/capabilities/default.json` | النافذة لا تملك إلا أوامرها |
| `tools/fetch-shell-fonts.py` | ينسخ أربعة ملفات خط فقط إلى الحزمة |
| `.github/workflows/shell.yml` | يبني ويختبر على Ubuntu وWindows 11 في كل تغيير |

## 2. ما يعرضه، وما يقرأه

**يعرض:** حالة الحماية (سطر واحد)، العام والشهر بخط كبير، الإصدار أصغر، وزرّ المظهر.
**يقرأ:** من الخدمة المقيمة عبر الأنبوب المحلي `Command::Status`، ومن `release_age` شهر الإصدار
المحقون وقت البناء، ومن `l10n` النصوص العشر، ومن `messages` المفاتيح.

**ثلاث حقائق لا تُخالف:**

1. **لا جواب من الخدمة = «لم يُتحقق منه بعد»**، لا «أنت محمي». الأنبوب الصامت ليس دليل حماية.
2. **لا شهر في البناء = لا تاريخ.** تُعرض النسخة وحدها؛ الشهر لا يُستنتج من طابع ملف.
3. **لا شريحة تحديث إلا بعد فحص فعلي.** الشريحة `None` اليوم لأن الفحص لم يُوصل بعد؛ لا يُخترع
   «يوجد إصدار جديد».

ولو كان النصّ مفقودًا من ملفات اللغات، تُعرض **المفتاح نفسه** (`state.protected`) بدل فراغ صامت —
فالعيب يُرى ولا يُخفي.

## 3. لماذا خارج مساحة العمل الجذرية

`Cargo.lock` في الجذر يُبنى بـ`--locked` في كل بوابة، وإضافة عضو جديد تغيّره. و`tauri` يجلب شجرة
تبعيات كاملة لا يمكن توليد قفلها إلا على جهاز فيه `cargo`. فالحزمة تعلن `[workspace]` فارغة
وتبني نفسها بـ`src-tauri/Cargo.lock` المستقل، وملفها **مُستثنى من Git** حتى يُولَّد عندك مرة ثم
يُلتزم.

**على Ubuntu:**

```bash
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev \
  librsvg2-dev libxdo-dev libssl-dev
python3 tools/fetch-shell-fonts.py
cd src-tauri && cargo run
```

**على Windows 11:** يستلزم WebView2 (موجود في النظام) و«Build Tools for Visual Studio» مع
C++؛ ثم الأوامر نفسها بلا `apt`.

**أول مرة:** بعد `cargo build` ناجح، التزم `src-tauri/Cargo.lock` ليصير البناء قابلًا للإعادة.

## 4. ما لا يفعله بعد — بصراحة

- **شاشة واحدة فقط.** التنبيهات والعزل والإعدادات واللغات لم تُنقل بعد؛ تُنقل واحدة واحدة، كل واحدة
  على أمر حقيقي.
- **لا شريحة تحديث.** تحتاج وصل `update_check` بمصدر الشبكة (D112) — ليس هنا.
- **لا مثبّت موقّع.** `bundle` مُهيّأ، والتوقيع ينتظر [D108](decisions.md).
- **لا يراقب الحماية فعليًا على Windows.** يعرض ما يقوله المقيم؛ وإنفاذ المقيم هو P1 في
  [المراجعة](reviews/priorities-2026-11-25.md).
- **الصور الرسمية** تُلتقط منه بعد استقرار الشكل، كما في [الإصدار المبدئي](release-alpha.md).

## 5. العلاقة بـ`ui-preview.html`

المعاينة **منضدة القياس**: فيها تُحسم الأشكال وتُراجع النصوص. وهذه الشاشة **التنفيذ**: تحمل نفس
الرموز، لكنها لا تحمل حيلة عرض ولا مبدّل حالات. أي فرق بينهما عيب في أحدهما، ويُصلح في المعاينة
أولًا ثم يُنقل.
