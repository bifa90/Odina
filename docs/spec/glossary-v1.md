# Odina — المفردات (Glossary) v1

> **الحالة:** ✅ ملزم — 2026-11-18
> **المرجع:** `docs/spec/design-system-v1.md` §6أ.1 · `docs/odina-agent-prompt-v17.md` §3.9
> **الغرض:** كل مصطلح أمني يظهر في الواجهة له **سطر واحد** يشرحه، وهذا السطر هو ما يراه
> المستخدم في `tooltip`. وما يحتاج أكثر من سطر يفتح **بحثًا** بلغته، لا فقرة في الشاشة.

---

## 1. لماذا ملف منفصل

الشاشة التي تشرح كل شيء داخل نفسها تصير وثيقة، والوثيقة لا تُقرأ. لكن المصطلح بلا شرح
يترك المستخدم يقرر بلا فهم — وهذا أسوأ من الشرح الزائد.

الحل: **الشاشة قصيرة، والشرح على بعد نقرة واحدة**. وهذا الملف هو مصدر السطر الواحد.
وأي `data-tipkey` في `ui-preview.html` لا يوجد هنا **يُفشل البناء**.

## 2. المفردات المتاحة اليوم

| المفتاح | المصطلح | السطر الواحد | بحث؟ |
|---------|---------|--------------|------|
| `tip.quarantine` | معزول | نقلناه إلى مخزن مشفّر — مكانه الأصلي محفوظ ويمكن استرجاعه. | لا |
| `tip.suspended` | مؤقتًا | أوقفناه الآن. سيعود للعمل إذا سمحت له. | لا |
| `tip.confirmed` | مؤكد | بصمته موجودة في قاعدة التهديدات. ليس تخمينًا. | نعم |
| `tip.high_risk` | مشتبه بشدة | علامات قوية على خطر، ولم تتأكد البصمة بعد. | نعم |
| `tip.suspicious` | مشتبه | يبدو غريبًا: الاسم أو المكان أو السلوك. لم نتحقق. | نعم |
| `tip.pua` | خطر متوسط | ليس فيروسًا، لكنه يتجاوز حماية برنامج آخر. | نعم |
| `tip.signature` | قاعدة التهديدات | بصمات ملفات معروفة. تحديثها يجعل الحماية أحدث. | نعم |
| `tip.behavior` | الفحص السلوكي | يراقب ما يفعله البرنامج، لا اسمه. | نعم |
| `tip.proactive` | الحماية الاستباقية | تمنع الفعل قبل وقوعه بدل أن تكتشفه بعده. | نعم |
| `tip.pause` | إسكات التنبيهات | نُسكت النوافذ فقط. الفحص والمنع يستمران. | لا |
| `tip.turn_off` | إيقاف الحماية | لا فحص ولا منع. جهازك غير محمي أثناء ذلك. | نعم |
| `tip.exception` | استثناء | كل استثناء يخصّ قاعدة واحدة. تبقى بقية القواعد كما هي. | نعم |
| `tip.expert_mode` | وضع الخبير | يفتح الخيارات الدائمة والكاملة. لا كلمة مرور، ولا سؤال. | لا |
| `tip.wsh` | Windows Script Host | مشغّل سكربتات ويندوز (.vbs · .js). باب شائع للبرمجيات الخبيثة. | نعم |
| `tip.powershell` | PowerShell | أداة أوامر في ويندوز. مقيّدة افتراضيًا عند المصادر الخطرة. | نعم |
| `tip.macros` | ماكرو | أوامر داخل مستند Office. لا تعمل في مستند غير موقّع. | نعم |
| `tip.amsi` | AMSI | واجهة ويندوز تمكّننا من رؤية السكربت قبل تنفيذه. | نعم |
| `tip.wdac` | WDAC | سياسة ويندوز تمنع تشغيل ملف بعينه. | نعم |
| `tip.usb_trust` | جهاز غير موثوق | أول مرة نراه. يُفحص قبل أن يُفتح. | لا |
| `tip.tamper` | حماية العبث | لا يمكن إطفاء Odina بتعديل ملفاته أو قتل خدمته. | نعم |
| `tip.hash` | بصمة (SHA-256) | سلسلة تمثّل الملف كاملًا. تغيّر بايت واحد يغيّرها كلها. | نعم |
| `tip.heuristic` | مؤشر | علامة تُقاس وتُوزن، وحدها لا تكفي للحكم. | نعم |
| `tip.lvl1` | إسكات التنبيهات | لا نافذة ولا صوت، لكن الفحص والمنع يستمران: الملف المصاب يُعزل بصمت ويُعرض عند العودة. | لا |
| `tip.lvl2` | إيقاف الحماية | لا فحص ولا منع ولا تنبيه. الخدمة تعمل لكنها خاملة، والجهاز غير محمي. | لا |
| `tip.no_permanent` | لا إيقاف دائم | أقصى إيقاف ينتهي بإعادة التشغيل، وهذا الحدّ الوحيد الذي نفرضه. | لا |

> **`tip.lvl1` وأخواتها استثناء مقصود لقاعدة «≤ ٩٠ حرفًا».** القاعدة تحكم ما يُعرض
> **دائمًا** على الشاشة. وهذه لا تُعرض إلا بعد ضغط «لماذا؟» — فطولها هو سبب وجودها:
> الجملة القصيرة على الشاشة، والتفصيل خلف زر واحد. راجع §6أ.1.

## 3. قواعد الصياغة

| القاعدة | التفصيل |
|---------|---------|
| **سطر واحد، ≤ 90 حرفًا** | ما زاد يُختصر أو يُنقل إلى «بحث» |
| **بلا وعيد** | ❌ «سيُخترق جهازك» · ✅ «جهازك غير محمي أثناء ذلك» |
| **بلا تعليم صارم** | ❌ «يجب عليك» · ✅ «نستطيع…» أو وصف الحدث |
| **المصطلح كما يراه المستخدم** | «بصمة» لا `hash` · «استثناء» لا `exception` |
| **لا اختصار يخلق مصطلحًا** | ❌ «ح.م» · ✅ الكلمة كاملة |

## 4. محركات البحث — جدول باللغة لا شرط في الكود

| اللغة | المحرك | استعلام |
|-------|--------|---------|
| `ar` · `en` · `de` · `fr` · `es` · `pt-BR` · `hi` | Google | `{term} Odina` |
| `zh-Hans` | Baidu | `{term} Odina` |
| `ja` | Yahoo Japan | `{term} Odina` |
| `ru` | Yandex | `{term} Odina` |

**الاستعلام لا يحمل بيانات المستخدم:** المصطلح + «Odina». لا مسار، لا اسم ملف، لا بصمة.
الشرح عند الطلب ليس استثناءً من §9.3 (صفر تيليمتري) — بل تطبيق له.

## 5. بوابة القبول

- [ ] كل `data-tipkey` و`data-why`، وكل مفتاح `tip.*` مستعمل في `data-list-tip`، موجود في الجدول أعلاه. تلميح القائمة محلي حتى لو كان البحث متاحًا للمصطلح في الدليل.
- [ ] كل سطر يظهر دائمًا ≤ 90 حرفًا · والنص المخفي خلف «لماذا؟» بلا حدّ (بقدر ما يشرح)
- [ ] كل رقم على الشاشة يحمل `data-numeral`، ويطيع اختيار المستخدم (§6أ.6)
- [ ] `zh-Hans` ← Baidu · `ja` ← Yahoo Japan · `ru` ← Yandex · الباقي Google
- [ ] لا سطر يهدّد المستخدم أو يعظه
- [ ] كل مصطلح «بحث: نعم» له مدخل مقابله في `locales/*/odina.ftl`
