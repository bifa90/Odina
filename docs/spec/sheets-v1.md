# أوراق Google — المخطط الملزم (D117 · D119 · D120)

> **الحالة:** معتمد للتنفيذ. **المرجع:** §11.1 · D117–D120.
> **الحدّ الصريح:** الورقة **صندوق وارد ومراجعة وبيان**، وليست قاعدة البيانات. حدّ Sheets ≈ 10 ملايين
> خلية لا يحمل ملايين البصمات؛ قاعدة البصمات النهائية **أصل إصدار موقّع** (D114).

---

## 1. الورقة التي يقرأها البرنامج: `Release_Manifest`

**طريقة النشر:** ورقة منشورة للقراءة فقط على الويب بتصدير CSV
(`docs.google.com/spreadsheets/d/e/<id>/pub?output=csv`). البرنامج يقرأ **هذا الرابط وحده**، بطلب
`GET` واحد، مرة في الشهر كحد أقصى (D117).

**الصف الأول إلزامي بهذا النص حرفيًا** — أي اختلاف = الورقة غير مقروءة، و«غير مقروءة» تعني صمتًا لا
«أنت محدّث»:

```
version,release_month,installer_url,installer_sha256,db_generation,db_bytes,db_sha256
```

| العمود | مثال | القاعدة |
|---|---|---|
| `version` | `0.2.0` | ثلاثة أرقام. لاحقة مثل `-check.1` تُقبل وتُهمَل في المقارنة |
| `release_month` | `2026-12` | `YYYY-MM` فقط |
| `installer_url` | `https://github.com/bifa90/Odina/releases/download/v0.2.0/odina-public-windows-x64.zip` | يجب أن يبدأ بـ`https://github.com/bifa90/Odina/releases/download/` |
| `installer_sha256` | 64 حرفًا سداسيًا | بصمة الحزمة |
| `db_generation` | `7` | عدد صحيح، يتزايد |
| `db_bytes` | `94371840` | حجم القاعدة بالبايت |
| `db_sha256` | 64 حرفًا سداسيًا | بصمة القاعدة |

**قواعد سلوك البرنامج:**

- الصف بأعلى `version` هو المعتمد؛ بقية الصفوف تاريخ.
- لا تنزيل ولا تثبيت تلقائي: البرنامج يقول «يوجد إصدار أحدث» ويفتح صفحة الإصدار بقرار المستخدم.
- صف غير سليم (رابط بمضيف آخر، بصمة ناقصة، شهر خاطئ) ← **الورقة كلها تُرفض**، لأن صفًا لا يمكن
  التحقق منه ليس صفًا.
- قبل أي تنزيل كبير (المثبّت أو القاعدة) تُعرض رسالة الحجم، وتُضاف كلمة «محدود» إن كان الاتصال
  محدودًا — التحذير يخصّ **التنزيل** لا فحص الإصدار (فحص الإصدار بضعة كيلوبايت).

## 2. الورقة التي تُستقبل فيها البلاغات: `Submissions`

**الطريقة:** نموذج Google مرتبط بورقة، والبرنامج يرسل `POST` واحدًا (D119). لا حساب ولا سرّ في
الثنائي. حقول النموذج هي **حقول §11.1 الستة عشر بحروفها**:

```
sha256 · size · header_hash · tail_hash · pe_hash · tlsh · name_pattern ·
path_pattern · attributes · behavior_score · behaviors · family ·
app_version · db_version · ts · ui_lang (اختياري)
```

| العمود في الورقة | القاعدة |
|---|---|
| `ts` | ثوانٍ Unix بتوقيت UTC |
| `behaviors` | رموز مفصولة بـ`;`، كل رمز ≤ 64 حرفًا، بلا فواصل داخلية |
| `family` | **اسم الخطر**، لا اسم الملف. اسم الملف يبقى على جهاز المستخدم |
| `name_pattern` | **نمط** بلا فواصل مسارات (`????????.exe`) |
| `path_pattern` | **موقع مطبَّع (D121)**: يبدأ برمز بيئة ويندوز وينتهي بـ`*.امتداد`، مثل `%TEMP%\*.exe` أو `%USERPROFILE%\Downloads\*.exe`. البرنامج يرفض أي قيمة ليست بهذه الصورة، ويرفض البلاغ كله إن وجد مشاركة UNC أو بريدًا أو SID |
| `ui_lang` | رمز اللغة فقط، غير مربوط بأي معرّف جهاز |

**أعمدة يضيفها الخادم (Apps Script)، لا يرسلها البرنامج:**

| العمود | الغرض |
|---|---|
| `Repetition_Count` | يرتفع بكل بلاغ مطابق يصل في **جلسة مختلفة**. البرنامج يرفض تكرار البلاغ في الجلسة نفسها |
| `First_Seen` · `Last_Seen` | تاريخ أول وآخر بلاغ |
| `Status` | `جديد` · `قيد المراجعة` · `مقبول` · `مرفوض` · `مكرر` |
| `Reviewer` · `Note` | من راجعه ولماذا — الرفض مسجّل لا محذوف |
| `Behavior_Score_Max` | أعلى درجة وصلت مع البلاغ، لعتبة الترقية `≥ 85` |

**عتبة الترقية التلقائية (§11.1):** `Repetition_Count ≥ 3` **و** `Behavior_Score ≥ 85` ← يُرشَّح
الصف إلى `Confirmed_Threats`. ومع ذلك **لا يدخل القاعدة تلقائيًا**: D109 يطلب أصلين مستقلين في
المنشأ، وبلاغ المستخدم ليس أصلًا مستقلًا (D119).

## 3. بقية أوراق §11.1

| الورقة | الحالة |
|---|---|
| `Confirmed_Threats` | مُعتمدة كبصمات مقبولة للمراجعة؛ **لا عمود لغة** (§4.8) |
| `Families` | معرّفات آلية للعائلات، لا جمل وصفية |
| `Trusted_Allowlist` | سماح موثّق بسبب ومسؤول؛ **لا عمود لغة** |
| `Release_Manifest` | §1 أعلاه |

## 4. دورة الحياة (D120)

1. الورقة تبدأ **فارغة** بترويسات §1 و§2 فقط.
2. البلاغات تتراكم في `Submissions`، والمراجعة تُغلق كل صف بحالة.
3. عند كل إصدار: تُبنى القاعدة، ويُحدَّث `Release_Manifest` بالجيل والحجم والبصمة، ثم **تُفرَّغ
   `Submissions` وتُنسخ نسخة احتياطية مؤرشفة** بتاريخ الإصدار.
4. النسخة الاحتياطية هي سجل المراجعة، لا تُحذف.

## 5. ما لا تفعله الأوراق

- لا تحمل القاعدة نفسها (الحجم والحدّ)، ولا مفاتيح، ولا بصمات توقيع.
- لا تُقرأ بأي حساب: كل قراءة منشورة مجهولة، وكل كتابة عبر النموذج/Apps Script.
- لا عمود لغة في `Trusted_Allowlist` ولا `Confirmed_Threats` (§4.8): اللغة ميزة في المستخدم لا في الملف.
