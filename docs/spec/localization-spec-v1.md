### 1.1 ما يُخرج من اللائحة ولا يعود

| اللغة | السبب |
|-------|-------|
| `zh-Hant` (التقليدية) | تُخدم بخط نظام مشترك، لكن **نصها لم يُكتب**. لا نُدّعي مشحونة وهي ليست كذلك |
| لغات أخرى | تُفتح للتبنّي بمساهمة المجتمع، لا بقرار فردي |

## 2. القاعدة الخطّية الحاكمة (§3.8)

> **اللغة ليست إشارة ثقة. أبدًا.**

| المكان | القاعدة |
|--------|---------|
| **التقييم** | لا كشف ترميز · لا نسبة حروف عربية · لا «لغة غريبة» في أي مؤشر |
| **USB** | أسماء عربية/صينية/روسية **حكم واحد** مع نظيراتها الإنجليزية |
| **الواجهة** | اللغة تُختار محليًا أثناء التثبيت — **لا GeoIP**، لا اتصال شبكة |
| **الترتيب** | ترتيب اللغات في القائمة **أبجدي محلي**، لا «الأهم أولًا» — إلا العربية أولًا في السوق الأول |
| **التخزين** | السجل بـ UTF-8 escaped ليُقرأ في أي لغة واجهة |

**لماذا هذا صارم إلى هذا الحد؟** لأن التصنيف باللغة يعني أن **اسم ملف بالعربية يبدو مشبوهًا** — وهذا يُحوّل الحماية إلى تمييز، ويجعل **مستخدمنا الهدف نفسه** أسوأ ضحية. قبول هذه القاعدة ليس تنازلًا سياسيًا بل **هندسة صحيحة**.

## 3. قواعد التعريب الست غير القابلة للكسر (§3.9)

| # | القاعدة | التفصيل |
|---|---------|---------|
| **1** | **ترجمة بشرية مراجَعة فقط** | لا ترجمة آلية في النصوص الأمنية (تنبيهات · أزرار · تحذيرات · تقارير) |
| **2** | **نفس المعنى ونفس مستوى التحذير** | ترجمة تُخفّف خطرًا (مثل حذف «أوقفناه مؤقتًا») = **خطأ أمني**، لا لغوي |
| **3** | **لا خطوط مشحونة إجبارية** | سلسلة fallback معلنة لكل لغة (§4) |
| **4** | **لا دمج نصوص على الهواء** | كل جملة كاملة = مفتاح واحد. Genders/Plurals تُبقى صحيحة |
| **5** | **pseudo-localization إلزامي** | 40% طول إضافي + أحرف موسّعة + RTL — لا كسر تخطيط |
| **6** | **لا شحن بلغة لم يراجعها ناطق أصلي** | ولا استثناء «لأنها بسيطة» |

## 4. سلاسل الخطوط — أول ما يراه المستخدم

### 4.1 الخطوط المضمّنة (604 KB شهرية، تُشحن مع المثبّت)

| اللغة | الخط | السلسلة |
|-------|------|---------|
| `ar` | IBM Plex Sans Arabic | `'IBM Plex Sans Arabic', 'Segoe UI', Tahoma, sans-serif` |
| `en` · `es` · `de` · `fr` · `pt-BR` | Inter | `'Inter', 'Segoe UI', system-ui, sans-serif` |
| `ru` | PT Sans | `'PT Sans', 'Segoe UI', sans-serif` |
| `hi` | Noto Sans Devanagari | `'Noto Sans Devanagari', 'Nirmala UI', sans-serif` |

### 4.2 الخطوط الآسيوية — من النظام أولًا، ثم CDN اختياري

| اللغة | خط النظام (فوري) | البديل | تنزيل CDN |
|-------|------------------|--------|-----------|
| `zh-Hans` | `Microsoft YaHei UI` | `SimHei` | Noto Sans SC — 6.83 MB |
| `zh-Hant` | `Microsoft JhengHei` | `PMingLiU` | Noto Sans TC — 6.34 MB |
| `ja` | `Yu Gothic UI` | `Meiryo UI` → `MS Gothic` | Noto Sans JP — 7.82 MB |

**القاعدة الحاكمة:** **خط النظام يُعرض أولًا، والتنزيل له وقته.**

| الحالة | السلوك |
|--------|--------|
| بلا إنترنت | خط النظام إلى الأبد — **وهذا مقبول، لا خطأ** |
| إنترنت متاح | تنزيل chunk-by-chunk لحاجة الشاشة |
| فشل التنزيل | **البقاء على خط النظام بلا إشعار مزعج** |
| بعد التنزيل | تفعيل فوري < 100ms، **بلا إعادة تشغيل** |

**لماذا خط النظام أولًا؟** لأن 6.83 MB تُنزَّل **بعد** أن يقرأ المستخدم أول جملة. من ينتظر الخط لا يقرأ شيئًا. **الشاشة ليست فارغة أبدًا.**

### 4.3 الأوزان والأحجام

| البند | القيمة |
|-------|--------|
| الأوزان | **400** و**600** فقط. لا 500، لا 700 (إلا PT Sans الذي لا يمتلك 600 → 700) |
| الأحجام | 12 · 14 · 16 · 20 · 28 · 40 |
| `font-display` | `swap` — النص يظهر قبل الخط |

## 5. بنية الملفات

```
locales/
├── ar/odina.ftl
├── en/odina.ftl
├── zh-Hans/odina.ftl
├── ja/odina.ftl
├── es/odina.ftl
├── ru/odina.ftl
└── hi/odina.ftl
```

### 5.1 قواعد المفاتيح

| القاعدة | المثال |
|---------|--------|
| **بادئة القسم** | `alert.confirmed.title` · `wall.behavior.title` · `path.label` |
| **مفتاح = جملة كاملة** | `alert.confirmed.body` = «تأكدت إصابة { $file }. أوقفنا تشغيله ولم نحذفه.» |
| **لا دمج** | ❌ `{{count}} ملف` + «تم الفحص» منفصلين |
| **لا متغيّرات لغوية** | ❌ «الملف» و«الملفات» تُبنى بالعربية بـ plural، بالإنجليزية بـ `s` — لا تُدمج |
| **مفتاح ناقص** | يسقط إلى **العربية** لا إلى الإنجليزية — لغة البلد الأول |

### 5.2 التوليد

```bash
python3 tools/gen_locales.py
```

يولّد الهيكل من قائمة مفاتيح مشتركة. **لا تكتب مفتاحًا بيدك** — أضفه إلى القائمة وأعد التوليد.

## 6. تخطيط RTL — ما ينكسر بلا هذا القسم

| العنصر | القاعدة |
|--------|---------|
| `dir` | على `<html>` لا على عنصر داخلي |
| **المسارت** | **دائمًا LTR معزول** — `<span dir="ltr" style="unicode-bidi:isolate">` |
| **الأيقونات الاتجاهية** | تُقلب بـ `scaleX(-1)` — والأيقونات المستقيمة **لا تُقلب** |
| الحقول الرقمية | LTR مع `text-align: start` |
| المسافة | `margin-inline-start` لا `margin-left` |
| الأسهم في النص | تُكتب كأصول اتجاهية لا كأحرف في النص |

**الاختبار:** أي اسم مستخدم عربي في مسار `C:\Users\أحمد\...` يجب أن يبقى مقروءًا بالاتجاه الصحيح.

## 7. pseudo-localization — الفحص الذي يكشف الكسر قبل المستخدم

| البند | القيمة |
|-------|--------|
| **طول إضافي** | **+40%** لكل نص |
| **أحرف موسّعة** | `ẞ · Ĝ · Ǆ · ﬔ` |
| **اتجاه** | كلاهما RTL وLTR |
| **الفحص** | لا نص مقتطع · لا تراكب · لا خروج عن الزر |
| **متى** | **في CI مع كل PR** — لا يدويًا |

**نمط عيّنة:**

```
افحص الآن  →  ẞǄĜافحـصـ الآنـ ẞǄĜﬔẞ
```

**ما يظهر بهذا الفحص:** الأزرار التي تتسع للإنجليزية ولا تتسع للعربية · الصفوف التي تنكسر بالصينية · التواريخ التي تنقلب بالـ RTL.

## 8. لغة الواجهة في التقرير

| البند | القاعدة |
|-------|---------|
| الحقل | `ui_lang` — **آخر حقل** في التقرير |
| المحتوى | رمز اللغة فقط: `ar` · `en` · `zh-Hans` |
| الغرض | معرفة أي لغة واجهة تُنتج أكبر عدد تصنيفات خاطئة |
| **لا** | لا يُربط بمعرّف جهاز · لا يكشف **لغة النظام** · لا المنطقة · لا البلد |

## 9. مراجعة الناطق الأصلي — كيف تُنظَّم بلا تكلفة

| الخطوة | الأداة | التكلفة |
|--------|-------|---------|
| استضافة سلاسل | Crowdin (مجاني للمشاريع مفتوحة المصدر) أو Weblate ذاتي | **0** |
| مراجعة | متحدث أصلي عبر المجتمع | **0** |
| تسجيل الحالة | `locales/<lang>/REVIEW.md` — من راجع، متى، وأي نسخة | **0** |

**لا يُشحن نص لم يُراجَع.** وإن لم يوجد ناطق أصلي: **اللغة تُعلَّق، لا تُشحن**. هذا أصعب قرار في الورشة، وهو الصحيح.
