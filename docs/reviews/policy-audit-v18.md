# مراجعة المشروع لإعداد الموجّه 18

**القرار:** لا يوجد في الشجرة مُثبّت يحقّق تعريف الحزمة الأساسية. يوجد ماسح يعمل، ومراقب ملفات مقيم قابل للاختبار، ومنطق احتواء، ومعاينة، وعميل لمتصفح الإنترنت. هذه أصول نبني عليها؛ **ليست خمسة مكوّنات مقبولة للإنتاج**. أول عائق هندسي ليس شكل الواجهة: ما نحتاجه في الأساس العام (الكاش والمقيم) مربوط اليوم بعلم بناء المختبر. [عقد المنتج](../odina-agent-prompt-v18.md) يحدّد العضوية والتشغيل؛ [خارطة العمل](../roadmap.md) تربط كل فجوة باختبار خروج.

## حدود الفحص وطريقة تكراره

الموضوع **الملفات التي يتسلّمها الوكيل في Git**، بما فيها المخفية والأصول والمخرجات المولّدة إذا كانت متتبَّعة. نقطة القطع: الالتزام `9c36a8527667c49c29b910e41c3dfbecd5dbf7dc` على فرع المراجعة، شجرة `2e1dc49d9b81192f46734e0994b222a13378d149`، قبل تغيير أي وثيقة. تضمّ الشجرة عمل المتصفح في PR تجريبي؛ ليست لقطة إصدار منشور. لا ندخل `.git/`، بيئات الأدوات، مخابئ البناء، ناتج الموقع غير المتتبَّع أو مرفقات المالك الخاصة في المقام.

قُرئت بايتات كل مسار وطوبقت مع معرّف blob في الشجرة. فُصل النص (UTF-8 بلا NUL) عن الثنائي؛ ثم فُهرست مواضع السياسات في النصوص، وتُتبعت الوظائف من تعريفات الحزم ونقاط الدخول إلى تنفيذها، واختباراتها، وما يدخل الـZIP أو الموقع. فُحصت الموارد بحسب نوعها بدل عدّ كل مقطع خط «ميزة». هذا **جرد كامل ومراجعة للسياسة ومقدار التنفيذ**؛ لا ادّعاء بمراجعة أمنية لكل سطر، أو تقييم جمالي لكل صورة، أو مصادقة مترجم على عشر لغات.

من أي نسخة Git تحوي الالتزام، هذه **القائمة الفردية** (المسار، النوع، هوية المحتوى، الحجم)، ثم ملخّص مستقل قابل للمقارنة بالجدول:

```sh
rev=9c36a8527667c49c29b910e41c3dfbecd5dbf7dc
git rev-parse "$rev^{tree}"
git ls-tree -rl --full-tree "$rev"
git ls-tree -rl --full-tree "$rev" | awk -F '\t' '{
  split($1,m," "); split($2,p,"/"); k=($2 ~ /\// ? p[1] : "(root)");
  n[k]++; b[k]+=m[4]; total++; bytes+=m[4]
} END {for (k in n) print k, n[k], b[k]; print "TOTAL", total, bytes}' | sort
```

## التعارضات التي غيّرت الخطة

- **عتبة اشتباه ملف ≠ تنشيط مراقب الجهاز.** كان نص الحماية يقصر الجدار الثاني على درجة 50% فما فوق، والموجّه يوقظه لكل جهاز جديد ويكتفي بالجدار الأول في الفحص السريع. تُحفظ عتبات الحكم، وتنفصل عنها أربع مهام مؤقتة وتفضيل دائم مستقل (D50). وصول وسيط سليم يستدعي تقييم USB، لا ادّعاء إصابة. الإسكات لا يجبر الدائم، والإيقاف الصريح النافذ لا تلغيه مهمة جديدة.
- **التسمية ≠ الصلاحية.** نقرة المتصفح على «فحص بـ Odina» ليست فحص Explorer ولا حدثًا سلوكيًا. `ready` لنقطة IPC لا يعني اكتمال تغطية المراقب؛ ومشاهدة التغيير لا تعني منعه. لذلك تبدأ الخطوات بعقد البيانات وسلامة المقيم قبل عرض «أنت محمي».
- **الحادثة ≠ الوصفة.** لا نجعل التحقق من الحادثة أو صندوق العزل متوقفًا على تنزيل الأتمتة. وفي الاتجاه الآخر، لا يصبح تخزين وصفة محلية إذنًا بصيانة الجهاز. احتُفظ بأدلة D47 وتاريخ التعبئة، وفُصل مسار الأساس عند غياب الإضافة عن مسار الإنقاذ الآلي.
- **النسخة العامة ≠ الحزمة الأساسية المكتملة.** «Public / Check» حدّ لقياس الأداء، و«Tier A/B/C» كثافة بيانات، و«أساسي / اختياري» حد لوظائف المنتج. كان خلط المحاور يسمح بشحن CLI أو إسفين USB وتسميته الأساس. صحّحت §§0 و5 و10 و29 و34 هذا الاستنتاج.
- **المعاينة ≠ مُثبّت أو نص معتمد.** نصوص الحالة وتلميح `settings.repair_db.help` تصف أمثلة وتعبئة D47. قبل K5 يُراجع النص العربي والتحذير المزدوج وحالة الإضافة، ثم تُراجع الترجمات وتُجدّد المشتقات من مصادرها. لا تعديل للكتالوجات أو للأحكام أو لتفضيلات المستخدم في مراجعة السياسة. الترخيص النافذ [موزّع بحسب النطاق](../../LICENSING.md)، واللغات العشر محلية حسب D18؛ خيارات الترخيص واللغات القديمة ليست أوامر تنفيذ.

**سؤال لم نحسمه نيابة عن المالك:** في [مواصفة USB، القاعدة الأولى](../spec/usb-security-spec-v1.md) قد يكون ملف `autorun.inf` سليمًا وغير موقّع معًا. أيُمنع التشغيل التلقائي كوقاية أم تُعلن إصابة مؤكدة؟ سُجّل التعارض Q19 قبل قبول G2؛ لا تعديل لأوزان الكشف ولا افتراض أن الاسم دليل إصابة.

## التحقق من تعديل السياسة نفسه

- نجحت بوابات المستودع المحلية **14/14**، ومنها الروابط والتعبئة والخطوط؛ ونجحت مطابقة نصوص إضافة المتصفح واختباراتها الثلاثة في Node. `i18n-lint`: صفر أخطاء و141 تحذيرًا، فلا نعلن اعتماد النصوص.
- على Linux، نجح تنسيق Rust، و**158 اختبارًا** لمساحة العمل، ثم **5 اختبارات G1 واختبار المقيم** في بناء release ذي العلم `instrument`. أعيد فحص شجرة تبعيات CLI العام: من حزم Odina يعتمد على النواة وحدها. استُخدمت نسخة عمل مؤقتة بمصادر تبعيات محلية بالإصدارات المقفولة لتعذّر سجل Rust في البيئة؛ لم تتغير مانيفستات المشروع أو قفله.
