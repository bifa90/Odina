# «فحص بـ Odina» — قائمة المتصفح فقط (D48)

من قائمة النقر بالزر الأيمن اختر **فحص بـ Odina**. لا يعمل شيء من الإضافة قبل الاختيار. التحديد هو الرابط المنقور في صفحة محلية، أو عنوان صفحة `file:` نفسها؛ قد يكون ملفًا أو مجلدًا أو جذر قرص. هذه **ليست** قائمة Explorer أو Dolphin، ولا إضافة لتنزيلات المتصفح. تعمل الخدمة المقيمة بصورة مستقلة عن الإضافة.

| التحديد أو الحكم | ما يحدث |
|---|---|
| رابط ويب، صفحة بعيدة، مشاركة UNC، أو ملف لم يُنزَّل | صمت. لا طلب للمصدر، لا قراءة لذاكرة المتصفح أو سجل تنزيلاته، لا استنتاج من الاسم أو من اسم النطاق. لفحص نسخة محلية، اخترها من صفحة ملفات محلية داخل نطاق الخدمة. |
| ملف داخل النطاق له حكم منشور سليم | صمت، دون قراءة محتوى جديدة. `monitor` أو مجهول أو حكم مسحوب أو خدمة متوقفة أو خارج التغطية: صمت أيضًا، **لا نسميها سليمة**. |
| مجلد/جذر قرص داخل النطاق | بحث في **جدول النتائج المنشورة** فقط. تتقدم الإصابة المؤكدة ثم الاشتباه. غياب موجب ليس شهادة سلامة للقرص؛ لا تُفحَص شجرة جديدة، ولا يُتَتَبَّع رابط رمزي. اختيار أبٍ للنطاق لا يوسّعه. |
| مشتبه / عالي الخطورة | نافذة محلية: «هذا الملف مشبوه». يُشرح أن **فحص عميق** سيقرأ ملفًا واحدًا للتحقق منه ولن يغيره. **تجاهل** هو الزر الذي يأخذ التركيز. إغلاق النافذة أو تركها لا يبدأ العمل. للمجلد يُختار أول مشتبه به بترتيب المسار النسبي، ويُثبَّت ذلك الاختيار. |
| ضغط المستخدم «فحص عميق» | العامل المقيم يعيد قراءة الملف المحدد وحده: مسبار Bloom ثم SHA-256 كامل من المقبض نفسه حتى لنتيجة Bloom السالبة؛ لا تلميح كاش محل القراءة ولا تصدير للبصمة. سقف 512 MiB. الملف المتغير/المتعذر أو الإيصال المنتهي → مجهول، لا قرار ضد الملف. |
| مؤكد (ابتداءً أو بعد الفحص العميق) | نافذة نتيجة، لا حظر ولا نقل. يظهر «انقله إلى العزل» **معطّلًا مع السبب**: لا يوفّر `serve` صندوق عزل إنتاجيًا قابلًا للاسترجاع. لا بدّ من موافقة مستقلة وعقد عزل حقيقي وفق D47 قبل تفعيله. لا نقول «أوقفنا تهديدًا معروفًا» ولا نعرض «متابعة المعالجة» بلا إيصال منع من جدار تنفيذ حقيقي. |

لا محتوى محقونًا في الصفحات، ولا تتبع أو تبليغ أو تعديل للمتصفح. الصلاحيتان الوحيدتان `contextMenus` و`nativeMessaging`؛ لا `tabs` أو `downloads` أو `webRequest` أو صلاحية مضيف. سياسة صفحات الإضافة تمنع الاتصال (`connect-src 'none'`). رابط/بصمة/سجل لا يُرسل إلى **أي خادم شبكي**. افصل ذلك عن اتصالات المتصفح نفسه للتحديث أو المزامنة: ليست من Odina.

## البناء والتشغيل — Linux وWindows

تحتاج Rust وPython 3.8+، متصفح سطح مكتب، وحساب مستخدم عادي واحد للخدمة والمتصفح. ثبّت البرنامج في **مسار يخصك وغير قابل للكتابة من مستخدمين آخرين**؛ لا تنقل الثنائية بعد تسجيل مسارها. التثبيت هنا يدوي للتطوير، ليس إصدار متجر موقّعًا. افتح نطاقًا **محليًا فعليًا** بتهجئته الأصلية؛ لا شبكات مركّبة أو أقراص معيّنة لشبكة أو ملفات سحابية عند الطلب، ولا خدمة ذات امتياز أعلى. لا تهيّئ قرصًا ولا تُغيّر صلاحيات حماية النظام.

```sh
cargo build --release --locked -p odina-browser-host
cargo build --release --locked -p odina-cli --features instrument
# طرفية 1: مثال صغير سليم. يمكن تحديد مجلد محلي آخر أو جذر القرص نفسه.
./target/release/odina serve tests/fixtures/safe --service browser
# طرفية 2: READY تعني النقطة جاهزة فقط؛ انتظر watching:true
./target/release/odina status --service browser
```

في PowerShell استعمل `target\release\odina.exe` و`target\release\odina-browser-host.exe`؛ مرّر الجذر مثل `'D:\'` إن أردت القرص كله (للخدمة جرد ابتدائي مستقل). ليس تثبيت الإضافة هو الذي يطلق الخدمة، ولا تحاول الإضافة تشغيلها إذا توقفت.

| المتصفح | وسيط المثبّت | كيف تحمّل الإضافة |
|---|---|---|
| Chrome | `chrome` | افتح `chrome://extensions`، فعّل وضع المطوّر، **Load unpacked** واختر مجلد الحزمة. |
| Edge | `edge` | افتح `edge://extensions`، فعّل وضع المطوّر، وحمّل مجلد الحزمة نفسه. |
| Firefox 140+ | `firefox` | افتح `about:debugging#/runtime/this-firefox` ثم **Load Temporary Add-on** واختر بيان الحزمة. يُعاد تحميل النسخة المؤقتة بعد إعادة التشغيل؛ يلزم توقيع موزيلا للتوزيع الاعتيادي. |

```sh
# لكل متصفح مطلوب، اختر chrome أو edge أو firefox (أو chromium للتطوير):
python3 tools/browser-setup.py pack --browser chrome --out out/odina-chrome
python3 tools/browser-setup.py install --browser chrome --binary target/release/odina-browser-host
# Firefox يحتاج حزمة منفصلة: background.scripts بدلاً من service_worker
python3 tools/browser-setup.py pack --browser firefox --out out/odina-firefox
python3 tools/browser-setup.py install --browser firefox --binary target/release/odina-browser-host
# PowerShell، مثال Edge:
py tools/browser-setup.py pack --browser edge --out out/odina-edge
py tools/browser-setup.py install --browser edge --binary target/release/odina-browser-host.exe
```

يثبّت السكربت **بيان المضيف فقط** في حساب المستخدم؛ لا يستبدل تسجيلًا قائمًا ولا يعدل تفضيلات المتصفح. ينتج `pack` **مجلدًا جديدًا**. تأكد أن المعرّف الظاهر في Chrome/Edge هو `nlbkfeimaaaoemglhmgmjmiefpnlhdlp` (المفتاح العام الثابت في البيان)، وفي Firefox `context-menu@odina.local`. اسم المضيف `org.odina.context`، دون wildcard. في Chromium تحقّق من إتاحة وصول الإضافة إلى عناوين الملفات في «التفاصيل» إن عرض المتصفح هذا الخيار. المتصفحات المحصورة بـSnap/Flatpak أو سياسة المؤسسة قد لا تبلغ مضيف المستخدم؛ اختبر نسخة سطح مكتب أصلية ولا تعطّل العزل لإجبارها.

- Linux: تحت `~/.config/{google-chrome,microsoft-edge,chromium}/NativeMessagingHosts/` (أو `XDG_CONFIG_HOME`)؛ Firefox في `~/.mozilla/native-messaging-hosts/`.
- Windows: بيان بمسار مطلق تحت `%LOCALAPPDATA%\Odina\NativeMessagingHosts`، وقيمة افتراضية تشير إليه تحت `HKCU\Software\{Google\Chrome,Microsoft\Edge,Mozilla}\NativeMessagingHosts\org.odina.context` بحسب المتصفح. لا HKLM ولا صلاحيات مدير.
- للإزالة: أزل الإضافة من صفحة المتصفح، ثم نفّذ `python3 tools/browser-setup.py uninstall --browser chrome` (بدّل الاسم، أو استعمل `py` على Windows)، ثم `odina stop --service browser` عند الخمول. لا يزيل ذلك أي ملف مفحوص.

## حدود الثقة والبروتوكول

1. [المستمع](../browser-extension/background.js) يتجاهل URL غير محلي قبل إطلاق المضيف، ولا يستقبل رسائل من صفحات الويب. حالة النافذة مؤقتة؛ في عنوانها معرّف عشوائي فقط، لا مسار ولا إيصال. [واجهة التنبيه](../browser-extension/notice.js) تأخذ العرض مرة واحدة من صفحة الإضافة ذاتها. النص من كتالوجات Fluent، والاسم المجرّد نص لا HTML.
2. [مضيف Rust](../crates/odina-browser-host/src/protocol.rs): `sendNativeMessage`، عملية واحدة لكل طلب؛ طول `u32` بترتيب الآلة + JSON UTF-8 عبر stdin/stdout. حد 32 KiB **قبل** التخصيص؛ لا سجل على stdout. عمليتان فقط: `{"op":"inspect","url":"file:///…"}` و`{"op":"deep","url":"file:///…","ticket":"…"}`. يمنع الحقول الزائدة/المكررة والتصعيد إلى `check/stop`، يفك الترميز مرة واحدة، ويرفض السلطة والمسارات الخاصة/عبور `..` والفواصل المشفرة وquery/fragment. لا يحل DNS أو يفتح ملف التحديد.
3. [IPC المقيم](design/resident-service-v1.md): مثيل ثابت `browser`، نفس UID/SID، UDS/Named Pipe فقط. `INSPECT=6` مفتاح مطلق UTF-8 يقيّد **بالمكونات** بجذر المشغّل دون canonicalize لمسار العميل. `VERIFY=7` إيصال `u64` بترتيب الشبكة ثم نفس التحديد. حد الرد لهما 128 بايتًا: `clean | unknown | suspicious | threat`، وإيصال للمشتبه الأولي فقط. لا جرد أو تقرير أو بصمة تعود إلى الإضافة؛ أوامر CLI السابقة لم تتغير.
4. [إيصالات الاشتباه](../crates/odina-resident/src/monitor/selection.rs): 16 عرضًا كحد، لمثيل واحد، صلاحية دقيقتين واستهلاك مرة واحدة. ترتبط بالتحديد والملف والمصالحة وجيل الحدث. يعاد التحقق قبل القراءة وبعدها، والعامل لا يقرأ إلا مفتاحًا سبق نشره. لا ثقة في حكم قديم بعد overflow. هذه حدود مصممة لعمليات **نفس المستخدم** لا sandbox أمام عملية محلية خبيثة تملك صلاحياته. حدود روابط/تغيير الأسماء في W2 قائمة.

## التحقق وإعادة القياس

```sh
cargo test --locked --release -p odina-cli --features instrument --test g1 --test resident
cargo test --locked --release -p odina-browser-host -p odina-cache -p odina-resident
node --test tools/browser/test-extension.mjs
python3 tools/browser-setup.py check-locales
# أغلق مثيل browser الخاص بك أولًا. الأداة تستخدم نسخة مؤقتة ولا تتصل بمثيل لا تملكه.
python3 tools/browser/verify.py --cli target/release/odina --host target/release/odina-browser-host \
  --samples 100 --deny-network --out native-lab.json
# Linux، لإضافة المتصفح الحقيقي (تنزيل تبعيات الاختبار فقط، ليس جزءًا من تشغيل الإضافة):
python3 -m pip install -r tools/ci/requirements-site.txt
python3 -m playwright install --with-deps --no-shell chromium
# أعد أمر verify السابق مع --chromium وملف خرج جديد.
```

- G1: متجه EICAR المعياري للقراءة فقط و20 ملفًا سليمًا، وكذلك استبدال بنفس الاسم/الحجم/mtime. لا تنفّذ العينة. يمكن تشغيل الشاهد الأصلي على Windows بدون `--deny-network`؛ لا يُحسب كاختبار seccomp. الاستعلام أثناء فقد الخدمة يعيد مجهولًا. اختبار Linux يقتل **العملية** إذا حاولت إنشاء socket غير AF_UNIX؛ تحقق شاهد موجب منفصل لـIPv4 وIPv6 من تفعيل المنع على الأبناء. لا ينطبق هذا الادعاء على كل عمليات المتصفح أو شبكة نظام الملفات.
- `suspicious` ليس حكمًا ينتجه الكتالوج الصغير اليوم من الاسم وحده؛ لم نرفع أوزانًا لاستخراجه. [اختبار الموافقة](../crates/odina-browser-host/tests/consent.rs) يزرع **صف اشتباه اختباريًا فقط**، ثم يمر فعلًا عبر ثنائية المضيف وIPC إلى فاحص Bloom/SHA، فيؤكد البصمة المعيارية؛ صفر قراءات عميقة قبل الإيصال، واحدة بعده، صفر عند إعادته. واجهة «تجاهل/فحص عميق» تُختبر بردّي مضيف مضبوطين في ملف متصفح مؤقت، لا بباب خفي في المنتج.
- **زمن مستقل:** في مختبر Linux المحلي، 100 إطلاق للمضيف في release، ملف نظيف بعد جرد 21 ملفًا، من قبل إطلاق العملية حتى فك الرد المكتمل بعد الخروج: **p50 1.708 · p95 2.514 · p99 2.764 · أقصى 2.866 ms**، 0/100 عند أو فوق 100 ms. ليس هذا توقيت متصفح. [الشاهد](../tools/browser/verify.py) يكتب جميع العينات، وأولها، ونسخة البيئة وبصمتي الثنائيتين؛ وضع `--chromium` يقيس **من دخول مستمع الاختيار في عامل متصفح فعلي إلى عودة حكم محلي**. لا يدخل فيه زمن تفكير المستخدم أو رسم قائمة النظام أو إيقاظ عامل بارد. لا وعد بـ100 ms لقراءة 512 MiB. زمن W2 `<10 ms` من تغيير الملف حتى نشر الحكم [مقياس ثالث مستقل](perf/resident-w2.md).

**جولة قبول يدوي** في كل متصفح: افتح مجلد خدمة محليًا بعنوان ملفات، افحص ملفًا سليمًا ثم المجلد/جذر القرص من صفحة الملفات. في صفحة ويب انقر رابطًا بعيدًا: مدخل واحد ولا نافذة ولا طلب شبكة سببه الإضافة. راقب عامل الإضافة وأدوات Network في وضع Offline، ثم كرر والخدمة متوقفة: لا علامة سلامة مصطنعة. افحص المجلد التجريبي الذي فيه متجه الاختبار دون تشغيله؛ ينبغي ظهور تنبيه مؤكد واحد بلا ادعاء منع وبلا نقل. تحقّق من التركيز وEsc، واللغة، والتسجيل والإزالة في Chrome وFirefox وEdge بإصدارات الجهاز. فحص الوقت من النقر الفيزيائي بعد سكون المتصفح حتى عرض التنبيه على جهاز المستخدم منفصل عن اختبار العامل الدافئ. لا تُدخل Tray أو Toasts أو Activity Log ضمن هذا القبول.
