# سجل القرارات (Decision Register)

هذا الملف هو **السجل الرسمي** لكل قرار مالك في مشروع Odina. الموجّه الأساسي
([`odina-agent-prompt-v19.md`](odina-agent-prompt-v19.md)) يحمل جدولًا مختصرًا
(المعرّف + جملة واحدة) ويُحيل هنا للتفصيل والنطاق وما ألغاه القرار.

**قواعد ثابتة**

1. أرقام القرارات (`D##`) ثابتة مدى الحياة؛ لا يُعاد استخدام رقم.
2. القرار المستبدَل يبقى في الجدول مع بيان ما ألغاه القرار الجديد.
3. لا يُنشأ قرار جديد إلا بجلسة حسم موثّقة؛ الحسم الشفهي لا يُسجَّل قرارًا.
4. كل قرار يحمل: النص · التاريخ · النطاق · ما يلغيه · حالة التنفيذ.

**حالات التنفيذ:** `مُعتمد` (ملزم، لم يُنفّذ) · `منفّذ` (موجود في الشجرة، بشاهد) ·
`مُقاس` (منفّذ مع قياس مسجّل) · `مؤجّل` (خارج نطاق الإصدار الحالي).
