# Odina Antivirus — ترتيب أولوية الأسواق (Market Rollout)

> **قرار رامي:** السوق اليمني هو **المرحلة 1**، والسوق العربي **المرحلة 2**. ثم بقية الأسواق لاحقًا.
> **ملاحظة مهمة:** اللغة ≠ السوق. كل اللغات تُشحن **تقنيًا** من v0.1 (§30)، لكن **الإعلان والتركيز** يتغيّر بحسب المرحلة. المستخدم يكتشف بقية الميزات بنفسه.

---

## المرحلة 1 — اليمن 🇾🇪

| البند | التفصيل |
|-------|---------|
| **الرسالة الأساسية** | *«افحص الفلاشة قبل أن تفتحها»* |
| **الميزة المُعلَنة** | USB Hot-Trigger (P0/P1) + العزل بدل الحذف |
| **لماذا هنا** | نقل الملفات بالفلاشات ناقل عدوى واقعي؛ أجهزة قديمة؛ إنترنت متقطّع |
| **الوعد المرفوض** | *لا نَعِد* بحماية سحابية أو تحديث لحظي — القاعدة محلية وتعمل بلا إنترنت |
| **القناة** | مجموعات التقنية المحلية، مراكز الصيانة، كليات الحاسوب، تيليجرام/واتساب |
| **مقياس النجاح** | ≥ 100 تثبيت + 10 تقارير موثّقة «فلاشة أُوقفت» |

## المرحلة 2 — العالم العربي 🌍

| البند | التفصيل |
|-------|---------|
| **الرسالة الأساسية** | *«حماية تفهم لغتك، ولا تجمع بياناتك»* |
| **الميزة المُعلَنة** | التعريب الكامل + RTL + صفر تيليمتري + كود مفتوح |
| **لماذا هنا** | لا يوجد مكافح عربي أصيل؛ فراغ سوقي واضح |
| **القناة** | منتديات عربية، يوتيوب تقني، GitHub بالعربية |
| **مقياس النجاح** | ≥ 1,000 مستخدم فعّال (بوابة G3 — §28.7) |

## المرحلة 3 — أسواق §20.3 (لاحقًا)

الصين/تايوان/هونغ كونغ، ثم إسبانيا وأمريكا اللاتينية، الهند، روسيا، البرازيل، اليابان، ألمانيا، فرنسا — **بنفس الترتيب**، مع إعلان يركز على ميزة مختلفة لكل سوق.

---

## قاعدة ملزمة

> **الكود لا يتغيّر بحسب المرحلة. الإعلان فقط هو الذي يتغيّر.**
> ممنوع الإعلان عن ميزة لم تُشحن، وممنوع حجب ميزة مشحونة عن سوق لأنها «ليست مرحلة الآن».
