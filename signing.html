سياسة توقيع الشيفرة

ما نُوقّعه، وما لا نُوقّعه، وأين يُحفظ المفتاح، وكيف تتحقق بنفسك.

الحالة اليوم — 2026-11-16 هذه السياسة منشورة قبل بدء التوقيع، ولم يُوقَّع أي ملف بعد. أول ملف موقّع سيُعلن في صفحة الإصدار مع بصمة SHA-256 الخاصة به. وحتى ذلك الحين يُوزَّع البرنامج كأرشيف ZIP محمول، لا كمثبّت بلا توقيع.

نُوقّع ملفات Windows التنفيذية فقط، ولا نُوقّع أي شيء لم يُبنَ من هذا المستودع.

البناء

كل توقيع يحدث على عدّاد GitHub Actions من الالتزام المُعلَن في سجل التغييرات؛ لا بناء محلي، ولا إعادة بناء قبل التوقيع.

المفتاح

لا نحتفظ بأي مفتاح توقيع. المفتاح في وحدة أمنية معزولة (HSM) لدى SignPath Foundation، ولكل عملية توقيع موافقةُ مشرف صريحة.

ما يُوقَّع

  • المثبّت: Odina-Setup-x.y.z.exe
  • حزمة المتجر: Odina-x.y.z.msix

ما لا يُوقَّع

  • قواعد البصمات — تُوقَّع بمفتاح Ed25519 منفصل، لأنها تُحدَّث أكثر من البرنامج.
  • الأدوات في مجلد tools/ — تُوزَّع بترخيص MIT كنص مصدري، لا كملفات تنفيذية.

التحقق

بصمة SHA-256 لكل ملف تُنشر في صفحة الإصدار قبل التوقيع وبعده. ويمكنك التحقق من التوقيع بنفسك على ويندوز:

Get-AuthenticodeSignature .\Odina-Setup-x.y.z.exe | Format-List Status, SignerCertificate

يجب أن يكون الحالة Valid، وأن يكون الناشر SignPath Foundation. وإن اختلفت البصمة عن المنشورة، فلا تشغّل الملف.

الإلغاء

إن بُني إصدار من شيفرة غير مُراجَعة، نُلغيه ونُعلن الإلغاء قبل أي شيء آخر.

التوقيع المجاني مقدَّم من SignPath.io، والشهادة من SignPath Foundation. Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Code signing policy

What we sign, what we never sign, where the key lives, and how to verify it yourself.

Status — 2026-11-16 This policy is published before signing begins. No build has been signed yet. The first signed build will be announced on its release page together with its SHA-256. Until then the program ships as a portable ZIP archive, never as an unsigned installer.

Only Windows binaries built from this repository are signed. Nothing else is.

Build

Builds run on GitHub Actions from the commit named in the release notes. There is no local build, and a binary is never rebuilt before signing.

Key

We hold no signing key. The key lives in SignPath Foundation's HSM, and every signing request requires explicit maintainer approval.

Signed

  • The installer: Odina-Setup-x.y.z.exe
  • The Store package: Odina-x.y.z.msix

Not signed

  • Signature databases — signed with a separate Ed25519 key, because they update far more often than the program.
  • Everything under tools/ — MIT-licensed and distributed as source, never as binaries.

Verification

A SHA-256 for every artefact is published on the release page, before and after signing. You can verify the signature yourself on Windows:

Get-AuthenticodeSignature .\Odina-Setup-x.y.z.exe | Format-List Status, SignerCertificate

Status must read Valid and the publisher must be SignPath Foundation. If the hash differs from the published one, do not run the file.

Revocation

If a build is ever produced from unreviewed code, it is revoked and the revocation is announced before anything else.
