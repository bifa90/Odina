# Odina · عدينة

> **مكافح فيروسات يمني — خفيف، صامت، وقاعدته بيانات ضخمة.**
> من تعز. سُمّي على **باب موسى** — البوابة التي منها دخل التاريخ مدينتنا.

**الحالة:** مشروع قيد التطوير، لا حزمة حماية عامة مكتملة. الفحص بسطر الأوامر للقراءة فقط؛ المقيم والمراقبة بعد تغيّر الملفات في بناء القياس. لا قاعدة تهديدات إنتاجية، ولا جدار سلوك مكتمل، ولا صندوق عزل إنتاجي. [الموجّه الأساسي v19](docs/odina-agent-prompt-v19.md) و[تقرير المراجعة الشاملة](docs/reviews/policy-audit-v18.md) يفصلان المطلوب عما يعمل اليوم.

## المهمة — ثلاثة أهداف لا تُفاوَض

| # | الهدف | المعيار |
|---|-------|---------|
| 1 | **خفيف على الموارد** | < 20MB RAM خمول · ≤ 0.1% CPU خمول (D52) |
| 2 | **قوي في الفحص، خاصة USB** | ≥ 99.5% من العينات المرجعية |
| 3 | **تغطية واسعة** | ≥250 عائلة مُغطّاة بإجراء؛ **لا هدف رقمي للحجم** (D61) |

**القاعدة الذهبية:** *«الحجم وسيلة، لا غاية. القوة هي الغاية.»*

## ما الذي يدخل في الحزمة؟

| الحزمة الأساسية المستهدفة | معناها |
|---|---|
| جدار قاعدة البيانات | محرك الفحص وقاعدة التهديدات وBloom Filter وSmart Cache، والخدمة المقيمة وIPC والمراقبة اللحظية. |
| جدار السلوك | **أساسي وغير مكتمل**. الرصد الدائم باختيار المستخدم بعد إعلامه باستهلاك الموارد وبأن الجدار ينشط تلقائيًا عند الخطر. ينشط مؤقتًا عند فحص ملف مباشرة، إصابة الجهاز، إدخال عنصر خطر، أو الفحص السريع للملفات المفتوحة والنقاط الخطرة. |
| واجهة سطح المكتب | الرئيسية ومركز التنبيهات وصندوق العزل القابل للاسترجاع والإعدادات واللغات. الصفحة المعروضة اليوم معاينة، لا تطبيق حماية. |
| الحماية الاستباقية والاستثناءات | قواعد منع محددة واستثناءات مرئية؛ منطق القرار متاح، لا إنفاذ Windows بعد. |
| تكامل مدير الملفات | أمر فحص من قائمة **Windows Explorer**، غير منفّذ. لا يتطلب متصفح إنترنت. |

**إضافتان اختياريتان:** [تكامل متصفح الإنترنت](docs/browser-integration.md) (نموذج اختُبر، ولم تحقق قائمة Firefox هدف الزمن)، و**أتمتة الإصلاح والصيانة** (غير إنتاجية). رفض أي منهما لا يسقط وظيفة أساسية.

## ماذا يحدث بعد تأكيد الإصابة؟

المستهدف احتواء الخطر، حفظ الملف وعزله عند تعذّر إنقاذه بأمان، والتحقق من زوال الإصابة قبل رفع القيود. هذا مستقل عن وجود الأتمتة. [وصفات الإصلاح](docs/spec/repair-component-v1.md) بيانات منفصلة عن قاعدة التهديدات. ZIP التجريبي قد يضم وصفتين تدريبيتين حتى حدّ 100 MB؛ يشغّل `repair-db --demo` التجربة في الذاكرة، ولا يعني ذلك أن الأداة أصلحت أو عزلت ملفًا في جهازك.

## أسس الثقة — دستور الواجهة

1. **الوضوح** — نقول ما حدث، لا ما هو التقنية.
2. **البساطة** — زرّان كحد أقصى. صفر إعداد مطلوب.
3. **الطمأنينة** — بلا حدث = بلا نافذة. ≤ 3 إشعارات يوميًا.
4. **معرفة العواقب** — عاقبة كل زر مكتوبة قبله لا بعده.

**وعند التعارض:** الأمان ← عدم الإزعاج ← الوضوح ← البساطة ← الجمال.

**قاعدتان لا تُخترقان:**
- **لا زر «حذف» في أي تنبيه** — الحذف فقط داخل صندوق العزل.
- **صفر تيليمتري.** لا شيء يُرسَل إلا بموافقتك الصريحة.

## اللغات

توجد كتالوجات عربية وإنجليزية وصينية مبسطة ويابانية وإسبانية وروسية وهندية وألمانية وفرنسية وبرتغالية برازيلية في المستودع والمعاينة. الثلاث الأخيرة موسومة كمسودات. يستهدف الأساس **اللغات العشر بلا تنزيل**؛ اختيار اللغة محلي بلا GeoIP. اكتمال المفاتيح لا يغني عن اعتماد النصوص الأمنية من ناطقيها؛ انظر [مواصفة التعريب](docs/spec/localization-spec-v1.md).
